Sharing a link makes isolation mandatory, not optional.

The idea assumed a Web Worker would be enough to run someone else's code "safely." A Worker protects the tab from a hang. It does not protect the app's own DOM, cookies, and storage from a stranger's code — and the moment a sandbox snippet is shareable by URL, that protection stops being a nice-to-have.

What the codebase actually said

Five facts, each with a consequence

Grepped, not assumed. Each of these changed what "safely" in the original idea had to mean.

  1. Static GitHub Pages deploy, no server.

    No custom response headers are possible for this deploy.

    Consequence: Cross-Origin-Opener-Policy / Cross-Origin-Embedder-Policy isolation is off the table entirely — the sandbox attribute is the only isolation primitive available at all.

  2. useStepPlayer.pump() calls generator.next() synchronously on the main thread today.

    There is zero isolation seam in the player as it exists.

    Consequence: a new StepSource abstraction is required so a worker-backed message stream and a local generator can both feed the same player — this is new engineering, not a wrapper.

  3. Snapshot shapes are per-category, with no runtime discrimination.

    Six distinct shapes exist (src/types/steps.ts); nothing picks a renderer from the shape itself.

    Consequence: user code has to target exactly one shape, chosen up front. SortStep is the only one with a reusable view — see the picker below.

  4. Nothing to build on.

    No CodeMirror/Monaco, no Web Worker, no eval/Function, no sandboxed iframe anywhere in src/ today.

    Consequence: this is greenfield infrastructure — a new build entry, a new worker bundle, a new dependency — not a variation on an existing pattern.

  5. An opaque-origin sandboxed iframe still permits outbound network requests.

    sandbox="allow-scripts" alone doesn't block fetch/XMLHttpRequest/WebSocket.

    Consequence: isolation here protects the app's own origin and the UI thread, not third parties a hostile snippet might call. Documented as an accepted risk below — no isolation primitive on a static site closes it.

Nothing here is faked — if your browser blocks part of this chain, the page says so instead of pretending.
