The decision that mattered most

null is the contract

Two of 45 labs existed when this shipped. Everything written afterwards could use any prose style, so the parsers return null on a non-match and the renderer falls back to the generic markdown path. That mattered more than the components.

Still open

Two things this left behind

  • blocked keys off lab status, not task status. 0045 still reads as blocked by 0044 even though 0044 is done — because 0044 has no research lab, by design. The flag conflates "waiting on unknown work" with "waiting on known work". Flagged during planning, deliberately left out of scope, not captured since.
  • docs/feature-lab-design.md still describes six lab sections. 0045 added a seventh (## Flows) and moved the meter to /7. The design doc was not updated.
  • A literal NUL byte shipped in sections.mjs. It was used as an escaped-pipe sentinel, which made git classify the whole 250-line module as binary — no diff, no blame. Caught two days later and swapped for an escape sequence. Worth remembering as a review blind spot: the tests all passed.
